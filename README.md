# Zombie Hunter - Jungle War

A browser-based zombie survival game built with HTML5 Canvas, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern web browser. No build step or dependencies are required.

## Controls

- Move with `W`, `A`, `S`, `D` or the on-screen mobile controls.
- Aim with the mouse and hold the left mouse button to fire.
- Press `Q` for Lightning, `E` for Grenade, and `R` for Shield.
- Press `Space` to shoot and `Escape` to pause.

## Files

- `index.html` - game interface and HUD
- `game.js` - game loop, entities, controls, combat, and progression
- `style.css` - visual styling and responsive mobile controls
